# 🎓 Le Wagon Bootcamp

Everything I built during [Le Wagon](https://www.lewagon.com)'s AI Software Development bootcamp (2026), in one place. Each project lives in its own repository and is linked below.

The bootcamp took me from Ruby fundamentals to shipping full-stack Rails apps with LLM features, working in teams on real products.

## 🚀 Team projects

| Project | What it is | Stack |
| --- | --- | --- |
| [**TermsAI**](https://github.com/ThibMarti/termsai) · [live](https://termsai.eu) | Chrome extension that turns Terms & Conditions and privacy policies into plain-language summaries. Capstone project, team of 4, built in 2 weeks | Rails 8, PostgreSQL, GPT-4o, Stripe, Chrome extension, Heroku |
| [**MacroChef**](https://github.com/ThibMarti/MacroChef) | Conversational AI meal planner: set your macros, get a plan, refine it by chatting. Team of 4, built in 1 week | Rails 8, PostgreSQL, GPT-4o, Hotwire, Bootstrap |

## What I learned

- **Ruby and OOP:** classes, blocks, enumerables and persisting data to CSV
- **Rails:** MVC, RESTful routing, Active Record, migrations, strong params and callbacks
- **Databases:** relational modelling in SQLite and PostgreSQL
- **Front end:** HTML, CSS, Bootstrap, Hotwire (Turbo and Stimulus)
- **AI:** integrating GPT-4o into Rails apps with the `ruby_llm` gem
- **Teamwork:** Git branching and pull requests, product pitching and Figma mockups
